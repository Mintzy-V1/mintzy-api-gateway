BEAR STREET — Thunder Client checklist
Base URL: http://localhost:3000
Prefix:   /api/v1/bear_street

Values used below:
  user_id     = 68a9792152e09e01f14b1da5
  session_id  = session_20260824054349_957f8917

Header on almost every request (except ones marked NO AUTH):
  Authorization: Bearer <your_jwt>
  Content-Type: application/json   (only when there is a JSON body)

Get JWT first:
  POST http://localhost:3000/api/v1/auth/onboard
  Body:
  {
    "apiKey": "<your_onboard_api_key>"
  }
  Copy `jwt` from the response into the Authorization header.

Copy Mongo `_id` later from GET /tradingsessions  →  REPLACE_MONGO_SESSION_ID
Copy config `_id` later from GET /saved-configurations  →  REPLACE_CONFIG_ID

Suggested order: Auth + GET first. Stop / delete / flush / force-stop LAST.

POST http://localhost:3000/api/v1/bear_street/saved-configurations

  "description": "temp config for API testing",
  "configuration": {

AUTH + START  (hits plugin — only if you really want to)
================================================================

32) Submit credentials
POST http://localhost:3000/api/v1/bear_street/credentials
Body:   (userId here is broker client id, NOT the mongo user_id.
         JWT user is still 68a9792152e09e01f14b1da5)
{
  "userId": "<broker_client_userId>",
  "api_key": "<broker_api_key>",
  "client_code": "<broker_client_code>",
  "password": "<broker_password>",
  "second_auth": "<broker_second_auth>",
  "source": "WEBAPI"
}
Optional extra fields: "base_url", "token"
This CREATES a new session. Prefer using the existing session_id below instead of calling this unless you need a fresh login.

NOTES
================================================================
- JWT user must own the session / config or you get 404 (same as leverage issue).
- REPLACE_CONFIG_ID must belong to JWT user 68a9792152e09e01f14b1da5.
- REPLACE_MONGO_SESSION_ID is the TradingSession `_id`, not session_2026...
- Skip 32, 34–37, 38–52 if you only want to inspect data and not change plugin/DB.
- POST /start is LIVE. POST /start-simulation is paper sim (strategy B). Do not treat them as the same.
- leverage_multiplier defaults to 1 when omitted.
