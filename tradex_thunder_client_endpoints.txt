TRADEX — Thunder Client checklist
Base URL: http://localhost:3000
Prefix:   /api/v1/tradex

Values used below:
  user_id     = 68a9792152e09e01f14b1da5
  session_id  = session_20260824054349_957f8917

Header on almost every request (except ones marked NO AUTH):
  Authorization: Bearer <your_jwt>
  Content-Type: application/json   (only when there is a JSON body)

Get JWT first:
  POST http://localhost:3000/api/v1/auth/onboard
  Body:
  {
    "apiKey": "<your_onboard_api_key>"
  }
  Copy `jwt` from the response into the Authorization header.

Copy Mongo `_id` later from GET /tradingsessions  →  REPLACE_MONGO_SESSION_ID
Copy config `_id` later from GET /saved-configurations  →  REPLACE_CONFIG_ID

Suggested order: Auth + GET first. Simulation / start / stop / delete LAST.

================================================================
SAVED CONFIGURATIONS
================================================================

23) List saved configs
GET http://localhost:3000/api/v1/tradex/saved-configurations
Body: none

24) Create saved config
POST http://localhost:3000/api/v1/tradex/saved-configurations
Body:
{
  "name": "Thunder Client Test Config",
  "description": "temp config for API testing",
  "configuration": {
    "strategy": "C",
    "time_frame": "3 hours",
    "candle": "75m",
    "use_broker_cash": true,
    "symbols": [
      { "symbol": "NIFTY", "capital": 100000, "stop_loss": 0.05 }
    ]
  }
}
Copy `_id` from response → REPLACE_CONFIG_ID

25) Get one saved config
GET http://localhost:3000/api/v1/tradex/saved-configurations/REPLACE_CONFIG_ID
Body: none

26) Update saved config
PUT http://localhost:3000/api/v1/tradex/saved-configurations/REPLACE_CONFIG_ID
Body:
{
  "name": "Thunder Client Test Config Updated",
  "description": "updated description",
  "configuration": {
    "strategy": "C",
    "time_frame": "3 hours",
    "candle": "75m",
    "use_broker_cash": true,
    "symbols": [
      { "symbol": "NIFTY", "capital": 120000, "stop_loss": 0.05 }
    ]
  }
}

27) Update leverage
PATCH http://localhost:3000/api/v1/tradex/saved-configurations/leverage
Body:
{
  "configuration_id": "REPLACE_CONFIG_ID",
  "leverage_multiplier": 1
}

28) Delete saved config   (DESTROYS THAT CONFIG)
DELETE http://localhost:3000/api/v1/tradex/saved-configurations/REPLACE_CONFIG_ID
Body: none
Do this last among config tests, or skip if you want to keep it.


================================================================
AUTH + START / SIMULATION  (hits plugin)
================================================================

29) Submit credentials
POST http://localhost:3000/api/v1/tradex/credentials
Body:   (userId here is TradeX broker userId, NOT the mongo user_id.
         JWT user is still 68a9792152e09e01f14b1da5)
{
  "userId": "<tradex_broker_userId>",
  "access_key": "<tradex_access_key>",
  "access_secret": "<tradex_access_secret>"
}
This CREATES a new session. Prefer using the existing session_id below unless you need a fresh login.

30) TOTP
POST http://localhost:3000/api/v1/tradex/totp
Body:
{
  "session_id": "session_20260824054349_957f8917",
  "totp": "123456"
}

31) Start simulation
POST http://localhost:3000/api/v1/tradex/start-simulation
Body:
{
  "session_id": "session_20260824054349_957f8917",
  "saved_configuration_id": "REPLACE_CONFIG_ID"
}
Optional extra field: "trade_date": "2026-08-24"

32) Stop simulation (handoff to live)
POST http://localhost:3000/api/v1/tradex/stop-simulation
Body:
{
  "session_id": "session_20260824054349_957f8917"
}

33) Start live trading
POST http://localhost:3000/api/v1/tradex/start
Body:
{
  "session_id": "session_20260824054349_957f8917",
  "saved_configuration_id": "REPLACE_CONFIG_ID"
}
saved_configuration_id is optional if the session already has one.

================================================================
NOTES
================================================================
- JWT user must own the session / config or you get 404.
- REPLACE_CONFIG_ID must belong to JWT user 68a9792152e09e01f14b1da5.
- REPLACE_MONGO_SESSION_ID is the TradingSession `_id`, not session_2026...
- Credentials body is TradeX-specific: userId + access_key + access_secret (not api_key/password).
- Skip 29–33 and 34–46 if you only want to inspect data and not change plugin/DB.
